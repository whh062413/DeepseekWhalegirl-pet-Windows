# References / 参考来源

This is an unofficial fan desktop pet for the DeepSeek whale-girl character. The animation artwork was generated with built-in ImageGen from a supplied character turnaround and an expression/pose reference. The final animation uses a metal basin for white rice. Prompt records are retained in `art/`.

本项目是 DeepSeek 鲸鱼娘的非官方二创桌宠。造型依据提供的三视图，端盆讨饭的姿态参考追加的表情图；美术由内置 ImageGen 生成，动作编排为本项目的原创改编，提示词保存在 `art/`。
